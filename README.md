# Handling Hand

Project page for **Handling Hand**, a low-cost, modular 16-DoF robotic hand. Its finger joints are MG90S hobby servos rearranged inside 3D-printed phalanx frames.

The hand was built by Team Handling at the School of Mechanical Engineering, Sungkyunkwan University, for the 16th KSME National Student Design Competition (2026).

- Live page: https://rachy103.github.io/handling-hand/
- This is a static site with no build step. To view it locally, serve the folder with any static web server, for example `python -m http.server`.

The page layout follows the [LEAP Hand](https://v1.leaphand.com/) and [Nerfies](https://nerfies.github.io/) project pages.
